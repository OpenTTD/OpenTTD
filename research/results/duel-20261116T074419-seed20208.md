portfolio gave the bot a 180-tile coal line. The bot built both stations, its rail A* found no path
("no rail path between the stations; removing them"), and it fell back to four single buses.

gives the bot only lines it can build (no bridge, tunnel or crossing in the track counts); on the
main stack it then built a 292-tile coal line and a 182-tile passenger line with trains. B
(unplanned) also stayed at four buses. The duel is rerun with the fix.
